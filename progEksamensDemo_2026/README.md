# Eksamensopgaveinfrastrukturering: 

Opret et nyt projekt i pycharm/valgfri IDE og kopiér indholdet af denne mappe derind.

## 1: Sørg for at de krævede libraries er installeret

* matplotlib
* pandas

```
 pip install -r requirements.txt
```

## 2: Se om du kan køre frameworkTest.py
```
 python frameworkTest.py
```

## 3: Gå ind i patienter mappen og løs opgaven
